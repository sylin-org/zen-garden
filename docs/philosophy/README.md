## The Core Ideas

If you only remember three things:

1. **Comprehensibility over capability.** A system that does less but can be understood is better than a system that does more but can't.

2. **Ownership over rental.** You care differently about machines you can touch.

3. **Permission to be small.** Not every system needs to scale infinitely. Most don't.
