## Variants

The Dell Wyse 5070 ships with two CPU options and two form factors, creating four main variants:

### CPU Variants

| CPU | Architecture | Cores | Base/Boost | TDP | AVX Support |
|-----|--------------|-------|------------|-----|-------------|
| Intel Celeron J4105 | Goldmont Plus | 4C/4T | 1.5/2.5 GHz | 10W | **NO** |
| Intel Pentium Silver J5005 | Goldmont Plus | 4C/4T | 1.5/2.8 GHz | 10W | **NO** |

**Critical:** Neither CPU supports AVX or AVX2 instructions. This significantly impacts AI/ML workloads.

## Hardware Specifications

### CPU Details

Both CPUs are based on Intel's Goldmont Plus microarchitecture (14nm):

**Instruction Sets Supported:**
- SSE, SSE2, SSE3, SSSE3, SSE4.1, SSE4.2
- AES-NI (hardware encryption)

**Instruction Sets NOT Supported:**
- AVX, AVX2, AVX-512

**Impact:** Software requiring AVX (many ML frameworks, some databases) will either fail (SIGILL crash) or fall back to slower code paths.

Sources:
- [GitHub Issue - J4105 crashes with exit code 132](https://github.com/Finsys/dockhand/issues/47)
- [WikiChip - J4105 details](https://en.wikichip.org/wiki/intel/celeron/j4105)

### Memory

| Property | Value |
|----------|-------|
| Type | DDR4 SODIMM |
| Speed | 2400 MT/s (2133-3200 reported) |
| Slots | 1 (soldered) or 2 (depending on variant) |
| Official Max | 8 GB |
| Community Tested | 32 GB (works) |

Sources:

### Storage

| Type | Capacity | Interface | Notes |
|------|----------|-----------|-------|
| eMMC (onboard) | 16-64 GB | Internal | **Limited write cycles** |
| M.2 SSD (Extended only) | User-added | M.2 SATA | Recommended for databases |

**eMMC Warning:** The onboard eMMC storage has limited write endurance. Write-heavy workloads (databases, logging) should use external or M.2 storage.

The onboard flash appears as `/dev/mmcblk0` in Linux.

### Alternative Update Methods

If fwupd fails:

1. **USB Flash Update:**
   - Download BIOS from Dell Support
   - Copy .exe to USB drive (doesn't need to be bootable)
   - At boot, press F12 → "BIOS Flash Update" under "Other Options"

2. **Dell Command Update:** Works if Windows/ThinOS installed

Sources:
- [GitHub Gist - Wyse 5070 BIOS USB Update](https://gist.github.com/oreze/aa803b421a410acd169ccb6782531fe9)
- [Dell Support - BIOS Update Linux](https://www.dell.com/support/kbdoc/en-us/000131486/update-the-dell-bios-in-a-linux-or-ubuntu-environment)

### BIOS Access

- Press **F2** at boot for BIOS setup
- Press **F12** at boot for boot menu
- Default admin password: **Fireport**
- Boot mode: **UEFI only** (Legacy not supported)

Source: [Parkytowers - Wyse 5070 Linux](https://www.parkytowers.me.uk/thin/wyse/5070/linux.shtml)

## Firmware Update Procedures

### Method 1: fwupd (Recommended)

Primary update method via LVFS:

```bash
fwupdmgr refresh
fwupdmgr get-devices
fwupdmgr update
```

**Requirements:**
- Must be connected to AC power
- System will reboot after update

**Version Policy:**
- Minimum: 1.10.0 (warn if below)
- Recommended: 1.34.0 (current stable)
- Latest known: 1.36.0 (may not be in LVFS yet)

### Method 2: USB Flash (Fallback)

If fwupd unavailable or fails:

1. Download BIOS .exe from Dell Support
2. Copy to USB drive (no bootable preparation required)
3. Boot device, press F12
4. Select "BIOS Flash Update" under "Other Options"
5. Follow on-screen prompts

Download URL: https://www.dell.com/support/home/en-us/drivers/driversdetails?driverid=7t9r1

### Known Firmware Issues

**Version 1.25.0:**
- Issue: Update loop - fwupd re-offers same update after reboot
- Workaround: Use USB flash method instead

### Not Recommended

| Service | Status | Notes |
|---------|--------|-------|
| Ollama | ❌ Poor | No AVX = very slow inference |
| Elasticsearch | ❌ Poor | RAM hungry, write heavy |
| Milvus | ❌ Poor | RAM hungry, needs AVX |

### Ollama Specific Testing

The lack of AVX on J4105/J5005 means:
- Ollama will run but inference is **extremely slow**
- Expect ~0.5-2 tokens/second on small models
- Large models may not load at all
- Software may crash with SIGILL (illegal instruction)

The Wyse 5070 is popular in homelab communities for:
- Network services (DNS, DHCP, VPN)
- Reverse proxies
- Lightweight containers
