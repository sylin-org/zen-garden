Why We're Doing This

Good hardware is being thrown away.

62M tonnes of electronic waste generated every year. Most of it still works.

That laptop you replaced? The office PCs your company retired? The Raspberry Pi in your drawer? They're not obsolete. The market just moved on.

Meanwhile, small businesses pay hundreds per month for cloud services they could run themselves. Developers spin up databases on distant servers when a machine under their desk would do. Privacy-conscious users have no simple path to owning their own data.

We built Zen Garden because infrastructure shouldn't require a cloud account, and because hardware that works shouldn't become landfill.

What You Get

Everything you need, nothing you don't.

Remember hunting for the new server name when a machine changed? Services find each other now.

Three $50 thin clients running 24/7 cost $26/year in electricity. That's 96% less than the cloud equivalent.

Start open, experiment freely. Add security when you're ready, not before.

How It Works

Three commands to a working garden.

1

Turn any machine into a Stone

Create a bootable pendrive, plug it in, reboot. When it comes back up, it's a Stone.

# Create the installer pendrive $ garden-rake forge-stone --drive E: # Boot from it. That's it. Stone ready.
2

Plant an offering

Pick a service from the catalog. One command deploys it.

$ garden-rake plant mongodb # That's it. MongoDB is running on your Stone.
3

Connect from anywhere in the garden

Applications use Zen Garden connection strings. No IPs, no ports.

# In your app's config zen-garden:mongodb/myapp # Resolves automatically to wherever MongoDB is running
