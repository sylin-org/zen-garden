# local/ — gitignored working memory

`NOTES.md` here holds machine-specific and session-sensitive material:
environment details, deployment locations, credential LOCATIONS (never
values), and current session handoff state. It is deliberately untracked —
everything durable has already been promoted into tracked docs (`docs/MEMORY.md`
is the index). If `NOTES.md` dies with a machine, nothing normative is lost.
